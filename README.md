**Retail Sales & Profitability Analysis | Power BI**

Project Overview
An interactive Power BI dashboard built to analyze retail sales, profit, orders, and profitability using the Sample Superstore dataset.

**Key Features**
- KPI cards for Total Sales, Total Profit, Total Orders, and Profit Margin
- Sales trend analysis over time
- Category-wise sales analysis
- Region-wise profit comparison
- Interactive Category and Segment slicers

 **Tools Used**
- Microsoft Power BI
- DAX
- Data Visualization
- Sample Superstore Dataset

**Project File**
Download the `.pbix` file from this repository and open it using Power BI Desktop to explore the dashboard.
